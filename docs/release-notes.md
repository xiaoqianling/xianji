弦迹首个版本内置 4 段课程、16 节学习单元、11 张和弦图及 5 首六线谱。课程、试听、练习和主题支持离线使用，进度可通过自建服务同步。

- Windows x64 下载 EXE 安装。此版本未配置 Authenticode 证书，Windows 可能提示发行者未知。
- Android 下载已签名 APK，支持 Android 7.0（API 24）及以上。
- iOS 模拟器下载 ZIP。解压后用 `xcrun simctl install booted App.app` 安装到已启动的模拟器。真机分发需要单独配置 Apple 签名。
- 可用 `SHA256SUMS.txt` 校验附件。
